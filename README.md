# YEAB KHEMRA — Personal website

Static portfolio website with a Milky Way backdrop, orbiting planets, project cards, and contact links.

## Publish with GitHub Pages

1. Create a repository named `yeabkhemra.github.io` in the `yeabkhemra` GitHub account.
2. Upload the **contents** of this folder to the repository root. Keep the `assets` folder and include `.nojekyll`.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, then **main** and **/(root)**. Save.
5. Wait for GitHub Pages to finish deploying. The expected address is `https://yeabkhemra.github.io/`.

GitHub Pages makes the website publicly available. No build command or server is required.

## Editing

- `index.html`: content and navigation
- `style.css`: layout and visual styles
- `script.js`: motion controls and email copy button
- `space-scene.js`: galaxy and planet animation
- `assets/`: portrait, project logos, and background loops

The Pinterest reference URLs are retained in the HTML comments for the two video loops.
